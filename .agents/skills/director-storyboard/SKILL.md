# 导演镜头拆解（导演镜头脚本模板）

给定一段小说/剧本原文，产出可直接使用的**导演镜头脚本**。

范本：`F:\AI剧本\超神机械师第一章初生_导演镜头脚本_内容连贯性修复版.docx`

> ⚠️ **同步要求**：本文件是模板的**文档版**，运行时真源是
> `backend/app/services/director_storyboard_skill.py` 的 `DIRECTOR_STORYBOARD_SKILL` 常量
> （后端 FastAPI 直接调 LLM，读的是该常量）。**任一处修改必须同步另一处。**
>
> 为什么不直接读本文件：Dockerfile 只 `COPY backend/`，且 `.dockerignore` 排除 `*.md`，
> 容器里读不到 `.agents/skills/`，会造成 dev 与容器行为分叉。

---

## 第一步：确定镜数

动笔前先回答：剧本涉及几个不同的场景/地点？有几个关键情节转折点？哪些关键动作必须在画面上呈现？情绪有几个起伏波段？

判断原则：

- 每个场景切换至少需要 1 个环境交代镜头
- 每个情节转折至少需要 1 个反应/动作镜头
- 情绪发生显著变化的时刻至少需要 1 个表情/氛围镜头
- 镜头总数没有固定公式，由实际内容评估；短小的故事不硬凑，宏大的场面不偷工

**警告**：若不加思索地全部输出 25 镜（恰好 25），说明没有认真读剧本。不要被任何固定数字锚定。

## 输出结构（四段，顺序固定，不得调换）

### 段一 · 片头定调

第一行是机器行：

```text
GLOBAL_PREFIX：{全局风格前缀，逗号分隔的一句话：画风 + 世界观 + 色调 + 材质质感 + 氛围}
```

随后是项目信息卡：

```text
作品：{作品名}（{章节}·{章节名}）
风格：{整体风格关键词}
画质：{画质与渲染关键词}
镜头：{本片镜头语言基调}
光影：{光线策略}
动作：{动作设计基调}
比例：16:9
基调：{情绪走向，如「悬疑压迫 → 认知颠覆 → 危险降临」}

开场定调：{2-3 句，交代开场空间/氛围/人物处境，供首帧与氛围参考}
```

### 段二 · 分镜正文

每个镜头严格按以下模板块输出，镜头块之间用空行分隔：

```text
镜头{两位序号}：{镜头标题}（时长：{N}秒）

{氛围段：1-2 句，交代本镜的场景空间 + 人物状态 + 风格基调}

{起}-{止}秒： {画面描述}
{起}-{止}秒： {画面描述}
{起}-{止}秒： {画面描述}

{角色名}： "{台词}"
{角色名}（内心独白）： "{台词}"

摄影与视觉要求：
风格：{风格关键词，逗号分隔}
画质：{画质关键词，逗号分隔}
镜头：景别={值}｜角度={值}｜运镜={值}｜情绪={值}｜构图={值}｜转场={值}
光影：{主光源方向与性质、明暗对比、特效光}
动作：{本镜关键动作与物理细节}
比例：16:9，{质感定语}

【衔接提示→本镜】 {本镜如何承接上一镜头，以及本镜在因果链中的作用}
【结尾桥接→镜头{下一镜序号}】 {本镜结尾如何过渡到下一镜头，声音/画面/动作为衔接介质}
```

#### 块内字段规则

1. **分秒画面行** —— 每行格式固定 `起-止秒： 画面`（半角数字与连字符，如 `0-3秒：`）。
   单镜建议 2-4 行，区间连续、无重叠，末尾区间等于该镜头时长。
   描述须含动作、镜头运动、日漫演出特效、必要的内心活动。
2. **对白行** —— 仅在确有台词时输出，位于**最后一行分秒画面之后**。
   格式 `角色名： "台词"`；内心活动 `角色名（内心独白）： "…"`；画外音 `角色名（画外音）： "…"`；
   非人声 `广播（机械女声）： "…"`、`面板（机械音）： "…"`。无台词则整行省略。
3. **镜头字段（机器键值行，最重要）** —— `镜头：` 后的值**必须**是 `键=值`
   用全角竖线 `｜` 分隔的固定六键，顺序固定、不得缺项：

   | 键 | 取值 |
   |---|---|
   | 景别 | 远景 / 全景 / 中景 / 中近 / 近景 / 特写 / 大特写 |
   | 角度 | 平视 / 俯拍 / 仰拍 / 侧拍 / 低角度仰拍 |
   | 运镜 | 自由描述（固定镜头 / 缓慢推镜 / 急速拉远 / 横向平移 / 手持跟拍 …） |
   | 情绪 | **严格两个字**（紧张 / 压抑 / 愤怒 / 震惊 / 释然 / 期待 / 恐惧 / 温馨） |
   | 构图 | 居中构图 / 三分构图 / 框架构图 / 侧偏构图 |
   | 转场 | 见下方白名单 |

   > 这六个键是**下游视频拼接与资产匹配的强依赖**，必须精确输出。

4. **转场白名单（必须服务叙事）**：

   | 转场 | 适用 |
   |---|---|
   | 淡入 | 全片第一个镜头，开场专用 |
   | 硬切 | 同一场景内快速切换 |
   | 溶解 | 时间流逝、空间变换、回忆与现实切换 |
   | 推入 | 情绪骤然升级，强调关键信息 |
   | 拉出 | 情绪疏离、场景结束、人物退出 |
   | 闪白 | 回忆闪回、强烈冲击、真相揭露 |
   | 黑场过渡 | 章节/场景段落结束，情绪断点 |
   | 叠化 | 情绪层层叠加、平行时空交错 |
   | 匹配剪辑 | 上下镜头构图相似但内容/时空变化 |
   | 模糊过渡 | 梦境、幻觉、昏迷、意识模糊 |

5. **【首镜头】例外** —— 第 1 个镜头把 `【衔接提示→本镜】` 换为 `【首镜头】 {本镜埋设的信息锚点}`。
6. **末镜例外** —— 最后一个镜头把 `【结尾桥接→镜头NN】` 换为
   `【结尾桥接·首尾闭环】 {与开场的呼应关系，如声音闭环/信息链回收}`。

### 段三 · 导演阐述

```text
导演阐述：内容连贯性总纲

1. 因果链完整化
{列出贯穿全片的信息链，每条注明「埋设镜头 → 回收镜头 → 解释镜头」}

2. 时序忠实原文
{说明关键事件的时序如何与原文一致，特别是易被颠倒的顺序}

3. 台词零丢失原则
{列出原文全部关键台词及其归位镜头}

4. 模板结构不变
所有镜头严格遵循本模板（片头定调段 + 逐镜块 + 导演阐述），衔接与闭环说明以标注形式附于镜头块末尾。

总时长：{总秒数}秒（{镜头数}镜头）
```

### 段四 · 末尾机器行

```text
POST_CONSTRAINT：{全局负向约束，逗号分隔的一句话：人设统一、无崩坏、无水印文字、色调连贯等}
```

## 连贯性硬约束（核心质量线）

1. **空间连续性** —— 相邻镜头不得凭空跳场；场景转移必须在画面内完成（撞门冲出/拖行入屋/架出走廊），或在【衔接提示】中明确交代转移介质。
2. **动作匹配剪辑** —— 上一镜头的动作/姿态应在下一镜头的【衔接提示】中被承接，优先用相似构图或相似动作做剪辑点。
3. **声音叠化** —— 镜头之间优先用声音（脚步/心跳/机械音/广播/门轴声）作为过渡介质，而非单纯依赖画面切换。
4. **情绪递进** —— 沿叙事弧线自然递进，禁止情绪断崖；情绪值只能取两字词。
5. **景别节奏** —— 景别必须交替变化，**禁止连续 3 个镜头景别相同**。
6. **信息锚点回收** —— 前文埋设的物件/台词/信息，必须在后文至少回收一次，并在导演阐述中列明。
7. **台词零丢失** —— 原文关键台词必须全部保留并归位到正确镜头，不得以"节奏原因"删减。
8. **角色不变量** —— 角色的外貌/服装/发型等视觉特征在各镜头描述中必须完全一致。

## 输出纪律

- 只输出上述四段结构，**不要**任何开场白、结束语、解释性旁白或 Markdown 代码围栏。
- 不要输出"分析过程"，直接给出成品脚本。
- 每镜的 `镜头：` 键值行必须与其他镜头格式完全一致，否则下游解析会失败。
