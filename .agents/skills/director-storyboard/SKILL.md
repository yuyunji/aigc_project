# 导演镜头拆解（导演镜头脚本模板）

给定一段小说/剧本原文，产出可直接使用的**导演镜头脚本**。

范本：`F:\AI剧本\超神机械师第一章初生_导演镜头脚本_内容连贯性修复版.docx`

两条铁律，缺一不可，且互不冲突：

- **形式照范本** —— 结构、段落顺序、字段名、每个部位的篇幅（见「内容密度要求」）
  一律不得增删或改写。范本没有的段落不要加，范本有的部位不要省。
- **内容照原文** —— 情节、人物、在场者、结局、台词全部来自小说原文，
  不得虚构原文没有的事件（详见「连贯性硬约束」第 9 条）。

一句话：**用范本的壳，装原文的肉**。

> ⚠️ **同步要求**：本文件是模板的**文档版**，运行时真源是
> `backend/app/services/director_storyboard_skill.py` 的 `DIRECTOR_STORYBOARD_SKILL` 常量
> （后端 FastAPI 直接调 LLM，读的是该常量）。**任一处修改必须同步另外两处**
> （本文件 + `.claude/skills/director-storyboard/SKILL.md` 镜像）。
>
> 为什么不直接读本文件：Dockerfile 只 `COPY backend/`，且 `.dockerignore` 排除 `*.md`，
> 容器里读不到 `.agents/skills/`，会造成 dev 与容器行为分叉。

## 第一步：确定镜数

动笔前先回答：剧本涉及几个不同的场景/地点？有几个关键情节转折点？哪些关键动作必须在画面上呈现？情绪有几个起伏波段？

判断原则：

- 每个场景切换至少需要 1 个环境交代镜头
- 每个情节转折至少需要 1 个反应/动作镜头
- 情绪发生显著变化的时刻至少需要 1 个表情/氛围镜头
- **一场对话归一个镜头**：同一场对话的多轮台词必须留在同一镜内，不得为了凑镜数把一场对话拆到三四个镜头里
- 镜头总数没有固定公式，完全由原文内容决定。不要凑数，也不要压缩：把每个必须呈现的情节节拍各给一镜，写完即止
- 参照系：5000 字左右的一章，成熟分镜通常落在 8-12 镜。这是经验值不是目标值，一律以原文实际内容为准

## 输出结构

> **结构必须与范本一致**：范本里**没有**「作品信息卡」段，也**没有**「导演阐述」段。
> 不要输出「段一/段二/段三/段四」「片头定调」「分镜正文」这类段落标题。

**第一行**：一整行全局风格前缀，逗号分隔，不分段、不加标题、不加冒号前缀：

```text
{画风 + 世界观场景 + 色调 + 材质质感 + 氛围}，{主要角色外观设定：年龄/发色发型/服装/体态/气质}
```

**随后**：逐镜输出镜头块，**块与块之间用空行分隔**。每个镜头严格按以下结构：

```text
镜头{两位序号}：{镜头标题}（时长：{N}秒）

{氛围段：1-2 句、30-90 字，场景空间 + 人物状态 + 风格基调，须具体（写清地点/材质/光线/情绪），不要"气氛紧张"这类空话}

{起}-{止}秒： {画面描述}
{起}-{止}秒： {画面描述}
{起}-{止}秒： {画面描述}

{角色名}： "{台词}"
{角色名}（内心独白）： "{台词}"

摄影与视觉要求：
风格： {风格关键词，逗号分隔}
画质： {画质与渲染关键词，逗号分隔}
镜头： {本镜镜头语言的散文描述，逗号分隔，**必须依次点明 景别、角度、运镜（含速度/幅度）、构图 四个要素**，如「空镜起手，中景·平视，中速贴地跟拍，雨幕三分构图」}｜景别={值}｜角度={值}｜运镜={值}｜情绪={值}｜构图={值}｜转场={值}
光影： {主光源方向与性质、明暗对比、特效光}
动作： {本镜关键动作与物理细节}
比例： 16:9，{质感定语}

【衔接提示→本镜】 {本镜如何承接上一镜头，以及本镜在因果链中的作用}
【结尾桥接→镜头{下一镜序号}】 {本镜结尾如何过渡到下一镜头，声音/画面/动作为衔接介质}
```

## 块内字段规则

### 1. 分秒画面行

每行格式固定 `起-止秒： 画面`（半角数字与连字符，如 `0-3秒：`）。
单镜 3-4 行，区间连续、无重叠，末尾区间等于该镜头时长。

**每行 80-180 字**，必须写足三层信息：① 画面里在发生什么（人物动作、神态、物件）
② 摄影机怎么动（推拉摇移跟、景别变化、机位）③ 演出特效与物理细节（光影、粒子、特效线条、材质）。
只有一句概括（如"主角睁开眼"）不合格——那是分镜提纲，不是导演脚本。
画面中确有台词或内心独白时，**内嵌在画面描述里**用引号写出，同时在下方对白行逐字重复一遍。

### 2. 对白行

位于**最后一行分秒画面之后**。格式 `角色名： "台词"`；
内心活动 `角色名（内心独白）： "…"`；画外音 `角色名（画外音）： "…"`；
非人声 `广播（机械女声）： "…"`、`面板（机械音）： "…"`。

**本镜涉及的原文台词必须全部归位**：这场对话里有几轮台词，就输出几行对白，
不得只挑一句、不得拆散到多个镜头、不得遗漏。无台词则整行省略。
原文有字幕/片名浮现时，可加一行 `字幕： {字幕内容}`。

**内心独白要极度克制** —— 范本 8 个镜头加起来只有 5 条内心独白，多数镜头一条都没有。
独白是点睛，**不是搬运原文的通道** —— 原文成段的心理叙述不要整段抄成独白，
应转化为**画面意象**（分屏闪现两个念头 / 闪回碎片 / 特效线条 / 表情细节）
交给分秒画面行去表现。**每镜内心独白最多 1 条**。

### 3. 镜头字段（散文 + 参数，最重要）

摄影块的 `镜头：` 行由两部分拼成，中间用**全角竖线 `｜`** 分隔
（这是整块里唯一允许出现 `｜` 的地方）：

- **前半是散文** —— 逗号分隔的镜头语言，必须依次点明 **景别、角度、运镜（含速度或幅度）、构图**
- **后半是参数** —— `键=值` 固定六键，顺序固定、不得缺项

| 键 | 取值 |
|---|---|
| 景别 | 远景 / 全景 / 中景 / 中近 / 近景 / 特写 / 大特写 |
| 角度 | 平视 / 俯拍 / 仰拍 / 侧拍 / 低角度仰拍 |
| 运镜 | 自由描述，**必须带速度或幅度**（缓慢推镜 / 中速横移 / 急速拉远 / 轻微手持跟拍 / 固定镜头） |
| 情绪 | **严格两个字**（紧张 / 压抑 / 愤怒 / 震惊 / 释然 / 期待 / 恐惧 / 温馨） |
| 构图 | 居中构图 / 三分构图 / 框架构图 / 侧偏构图 |
| 转场 | 见下方白名单 |

> 散文与参数**必须互相吻合**：散文写了「俯拍」，参数就必须是 `角度=俯拍`，
> 不得一处说平视、一处写俯拍。
>
> 这六个键是**下游视频拼接与资产匹配的强依赖**。
>
> **每个键只能填一个值**，且必须来自上方白名单：
> - 禁止组合值 `全景→近景`、`中景/近景`、`近景-特写`
> - 禁止括号注解，`框架构图（门框）` 必须写 `框架构图`
> - 禁止白名单外的档位，`中近景` 必须写 `中近`
> - 情绪恰好两字，禁止 `紧张不安`、`极度压抑`

### 4. 转场白名单（必须服务叙事）

| 转场 | 适用 |
|---|---|
| 淡入 | 全片第一个镜头，开场专用 |
| 硬切 | 同一场景内快速切换 |
| 溶解 | 时间流逝、空间变换、回忆与现实切换 |
| 推入 | 情绪骤然升级，强调关键信息 |
| 拉出 | 情绪疏离、场景结束、人物退出 |
| 闪白 | 回忆闪回、强烈冲击、真相揭露 |
| 黑场过渡 | 章节/场景段落结束，情绪断点 |
| 叠化 | 情绪层层叠加、平行时空交错 |
| 匹配剪辑 | 上下镜头构图相似但内容/时空变化 |
| 模糊过渡 | 梦境、幻觉、昏迷、意识模糊 |

### 5. 首镜与末镜例外

- **【首镜头】** —— 第 1 个镜头把 `【衔接提示→本镜】` 换为 `【首镜头】 {本镜埋设的信息锚点}`
- **末镜** —— 最后一个镜头把 `【结尾桥接→镜头NN】` 换为
  `【结尾桥接·首尾闭环】 {与开场的呼应关系，如声音闭环/信息链回收}`

## 内容密度要求（按范本逐镜实测标定）

下表的达标线来自范本 8 个镜头的逐项实测统计，**不是建议值**。

「达标线」是硬性下限，低于它直接判定为不合格；「范本实测」给出该部位的真实分布，
**目标是写到中位水平** —— 达标线只是兜底，贴着下限写出来的脚本仍然是提纲。

| 部位 | 达标线 | 范本实测 |
| --- | --- | --- |
| 氛围段 | 1-2 句，30-90 字 | 27-85 字，中位 55 |
| 分秒画面行 | 3-4 行/镜，**每行 80-180 字** | 47-174 字，中位 103，均 105 |
| 每镜画面行总字数 | **不少于 240 字** | 237-415 字，中位 353 |
| 对白行 | 本镜涉及的原文台词**一条不漏**，且**每镜不超过 7 条** | 每镜 1-7 条，中位 3 条 |
| 内心独白 | **每镜最多 1 条**，原文心理叙述转画面意象 | 8 镜共 5 条（多数镜为 0） |
| 摄影与视觉要求 | 6 字段齐全，每字段不少于 12 字，须本镜专属（禁止跨镜复读） | 结构要求 |
| 括号标注 | 【衔接提示】【结尾桥接】各 **80-150 字** | 80-139 字，中位 107 |
| 单镜总字数 | **不少于 780 字** | 779-1081 字，中位 883，均 910 |

自查方法：写完后逐镜核对本表。若某镜的分秒画面行加起来读起来像"提纲"而不是"能直接照着拍的分镜"，
就是密度不足，必须补足细节重写。

> **只可借鉴格式与密度**：范例中的人物名、地名、台词、情节一句都不允许出现在你的输出里。

1930年代民国谍战动画风格，冷灰蓝与暖黄霓虹对比色调。上海法租界的雨夜街景，梧桐、黄包车、霓虹招牌与湿漉漉的柏油路面反射灯光。画面采用赛璐璐上色叠加胶片颗粒质感，低饱和冷调，人物轮廓干净利落。主角沈砚舟：28岁左右男性，黑色风衣、灰呢礼帽压得很低，身形颀长，眉眼冷峻，左颊有一道浅疤。苏曼卿：酒红色旗袍、珍珠耳坠，卷发齐肩，笑意不达眼底，身份成谜。

沈砚舟（内心独白）： "十点零七分。她从来没迟到过一分钟。"

## 连贯性硬约束（核心质量线）

1. **空间连续性** —— 相邻镜头不得凭空跳场；场景转移必须在画面内完成（原文已有的位移动作），或在【衔接提示】中明确交代转移介质。
2. **动作匹配剪辑** —— 上一镜头的动作/姿态应在下一镜头的【衔接提示】中被承接，优先用相似构图或相似动作做剪辑点。
3. **声音叠化** —— 镜头之间优先用声音（脚步/心跳/机械音/广播/门轴声）作为过渡介质，而非单纯依赖画面切换。
4. **情绪递进** —— 沿叙事弧线自然递进，禁止情绪断崖；情绪值只能取两字词。
5. **视觉多样性（硬约束）** —— **同一景别、同一角度、同一运镜、同一转场，在任意连续 15 个镜头内
   各出现不超过 3 次；全片不足 15 镜时，窗口就是全片**（例如 7 镜的片子，同一景别最多 3 镜）。
   整片只用平视、或只用中景，会让画面像 PPT —— 景别与角度的变化本身就是节奏。
   **景别是最容易偷懒的一项**：中景是叙事主力，但**不许让它吃掉近一半的镜头** ——
   远景/全景交代空间、近景/特写给情绪爆点，每一档都要有，写完回头数一遍。
   角度情绪语义：平视=客观/对等，俯拍=渺小/被审视，仰拍=高大/压迫，侧拍=旁观/疏离，低角度仰拍=威压。
   景别推进公式：远景（交代环境）→ 中景（推进叙事）→ 近景（传递情绪）→ 特写（制造高潮）。
6. **信息锚点回收** —— 前文埋设的物件/台词/信息，必须在后文至少回收一次。
7. **台词逐字照抄** —— 原文台词必须**一字不改**地归位到正确镜头，不得改写、缩写、换词、改标点，不得以"节奏原因"删减。原创台词只允许出现在原文没有台词的纯动作/环境镜。
   也**禁止在原文台词前后添加原文没有的句子**（原文只有"把他带下去做血液测试，我要马上看到报告！"，不得写成"海拉，这里的主管。把他带下去做血液测试，我要马上看到报告！"）。
8. **角色不变量** —— 角色的外貌/服装/发型等视觉特征在各镜头描述中必须完全一致，且与第一行的角色设定吻合。
9. **情节严格忠实原文（红线）** —— **禁止新增原文没有的情节事件**。
   - 人物做了什么、去了哪里、谁在场、结局如何，全部以原文为准。
   - 允许自由设计的只有**表现形式**：镜头语言、光影、日漫演出特效、画面构图、心理意象化处理。
   - 典型反例：原文写"十几个警卫一拥而上，把他押着转移到一间空的小黑屋，警卫锁死大门后尽数离开"，
     却改编成"他挣脱警卫、抢下电棍打晕两人后逃出基地" —— **这是新增情节，禁止**。
   - 反向提醒：原文里**已经写了**的冲突、围堵、打斗、追逐，必须如实呈现，不得因"看起来太激烈"而删掉。
     判断依据永远是原文，不是你的印象。
   - 如需补充原文留白的心理活动，只能以内心独白或意象化闪回的形式呈现，
     且不得改变原文的事实走向。

## 输出纪律

- 只输出「首行全局风格前缀 + 逐镜块」，**不要**任何开场白、结束语、解释性旁白或 Markdown 代码围栏。
- **禁止**输出「段一/段二/段三/段四」「片头定调」「分镜正文」「导演阐述」「作品信息卡」这类段落标题，
  也不要在开头罗列 作品/风格/画质/镜头/光影/动作/比例/基调 等分条信息卡——全局风格并进第一行。
- 不要输出"分析过程"，直接给出成品脚本。
- 每镜 `镜头：` 行都必须是「散文｜参数」两段式，`｜` 之后六个键一个不少，否则下游解析会失败。
- 输出前逐镜自查密度表：分秒画面行是否每行 80-180 字、画面行合计是否够 240 字、
  本镜台词是否一条不漏、括号标注是否够 80 字、单镜是否够 780 字。
  密度不足的镜头必须补写细节，不要交提纲。
