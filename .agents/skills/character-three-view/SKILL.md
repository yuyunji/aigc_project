# 人物角色三视图设定（日漫 2D 赛璐璐）

给定一段文案，按两步产出可直接投喂给文生图模型（如豆包 Seed）的角色资产 prompt。**每个角色独立输出一张「横向 16:9 角色设定表」prompt**，角色之间保持视觉特征严格区分。

## 第一步：角色内核提取

深度解析文案，输出清单表格。**出现两次的重要配角不得遗漏**，配角同样走完整流程。

| 姓名 | 性别（必须强调） | 确切年龄 | 身份职业 |
|---|---|---|---|
| （角色1） | 男 / 女 | 具体数字 | 具体身份 |

规则：
- 性别必须明确写出「男」或「女」，不得省略。
- 年龄要落到具体数字；文案未明确时，按身份/语境推定最合理年龄，并在表格后括注「推定」。
- 身份职业写具体（如「落魄剑客」「高中化学老师」），不写「主角」「路人」这类空泛词。

## 第二步：专业角色设定表（严格固定格式）

对每个角色，**严格**按以下模板逐项输出，不得漏项。全部视觉语言统一为**日漫 2D 赛璐璐风格**（扁平色块上色 + 清晰深色描边，非 3D 渲染、非写实）。

```text
画幅构图：横向 16:9 专业角色设定表，纯白色极简背景，无多余元素。

视觉风格：日式动漫赛璐璐风格（2D cel shading），扁平色块上色 + 清晰深色描边，
          非真人，高精度 2D 作画，动漫光影层次。

左侧特写：角色面部高清特写，日式动漫赛璐璐风格；确切年龄感、明确性别特征；
          基础发色为黑色或自然色，除非文案标注角色发色；发型具体清晰（2D 发丝分簇 + 高光，非 3D 毛发）；
          眼睛颜色为深棕色或黑色，双眼颜色一致；2D 赛璐璐皮肤上色，柔和阴影，非写实。

右侧三视图：角色全身标准三视图（正面、侧面、背面），站姿自然直立，
            2D 平涂 + 描边展示全身比例，非真人照片。

服饰设计（差异化要求）：
  上身服装：[根据人设设计：具体的款式、2D 布料平涂上色、颜色、剪裁细节，严禁默认西装]。
  下身服装：[根据人设设计：具体的裤装/裙装款式、2D 上色细节、颜色]。
  鞋履配饰：[匹配的鞋子；除非文案明确要求，否则不加冗余首饰，拒绝跨性别装饰]。
  除非文案明确标注「衣服破损」，否则服装完整无破损。

【核心规则】：多个角色之间的服装款式与色彩方案必须有显著区别，严禁撞衫。

【负向提示词参考】：no realistic, no photo, no photograph, no 3D, no render,
                    禁止写实, 禁止真人照片, 禁止3D渲染, 禁止3D建模
```

### 服饰差异化对照（多角色时必填）

输出完所有角色的设定表后，追加一张交叉对照表，确认无撞衫：

| 角色 | 主色系 | 上身款式 | 下身款式 | 鞋履 | 标志性特征 |
|---|---|---|---|---|---|
| （角色1） | 深蓝 | ... | ... | ... | ... |

若有任意两个角色主色系相同，必须调整其一，直至整表主色系互不重复。

## 第三步：组装最终生成 prompt

将上一步每个角色的设定表，合并为**一段连续的文生图 prompt**直接输出，作为该角色的最终资产图指令。合并顺序固定为：画幅构图 → 视觉风格 → 左侧特写 → 右侧三视图 → 服饰设计 → 负向提示词。可直接复制使用。

### 组装模板（每个角色复制一份，填入设定表字段）

```text
横向 16:9 专业角色设定表，纯白色极简背景，无多余元素；
日式动漫赛璐璐风格（2D cel shading），扁平色块上色 + 清晰深色描边，非真人，高精度 2D 作画；
左侧为{年龄}{性别}面部高清特写，{发型}、{眼睛颜色}双眼、2D 赛璐璐皮肤；
右侧为全身三视图（正面/侧面/背面），站姿自然直立；
上身{上身服装}，下身{下身服装}，鞋履{鞋履配饰}；
服装完整无破损；
no realistic, no photo, no 3D, no render, 禁止写实, 禁止真人照片, 禁止3D渲染。
```

> 占位符 `{...}` 直接从该角色的第二步设定表中取值替换；替换后应是一条无换行断句的连续 prompt（分号分隔即可），可直接投喂豆包 Seed。

## 输出纪律

- 只按上述结构输出，不额外添加说明、不写「这是一个很好的角色」之类开场白。
- 角色性别、年龄、发色、眼睛颜色必须前后一致，同一角色在「特写」与「三视图」中的描述不得矛盾。
- 若文案未提及角色发色/瞳色/服饰，用模板中的默认值（黑/自然色、深棕或黑），不得擅自加花哨设定。
